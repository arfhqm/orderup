# OrderUp Smart POS

A simple Smart POS system for small F&B businesses to manage menu items, take customer orders, calculate totals, and provide AI-powered menu recommendations.

## Tech Stack
- Frontend: Angular / React
- Backend: Spring Boot
- Database: MySQL
- AI Feature: AI menu recommendation / upsell suggestion

## Features
- View menu items
- Add items to cart
- Place customer order
- Store orders in database
- View order summary
- AI recommendation for add-ons or combos

## How to Run

### Backend
```bash
cd backend
mvn spring-boot:run
